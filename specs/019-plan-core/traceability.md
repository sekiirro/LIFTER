## F16 FR-034 cache-key carry-forward (S46-R1)

The F16 FR-034 clause is carried forward into FR-003 and SC-007 and into the owning task T020: if any cache is introduced for client plan views, its key includes the authenticated user, the plan identity, the plan version and the workspace; two plans with the same published version for the same user and workspace never share a cached result; and a test plus mutations (drop plan identity from the key -> test fails; drop plan version from the key -> test fails) are required. Video is never stored in a cached projection: F16 FR-034 forbids a Video resolution cache. F16 T051 remains PARTIAL until a task owns such a cache, and no cache is introduced by this change.
