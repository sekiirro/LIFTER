# Contract — Workout exports and Copy Prompt for AI

**Status**: spec-only draft (S42). No implementation. Every user-visible string requires PO approval byte-exact; no Arabic string is drafted here.

## 1. Export surface

| Option | Output | Availability |
|---|---|---|
| PDF | printable document (browser print / print CSS) | published revision, authorized actor |
| Excel | workbook built in the browser (ExcelJS) | published revision, authorized actor |
| `Copy Prompt for AI` | generated text copied to clipboard | published revision, authorized actor — role open (F17-MCQ-6) |

Only published revisions are exportable. Selection is explicit; if several revisions exist, the actor selects one and the output matches that revision exactly. Drafts, private notes outside the selected revision, and undelivered content are never exported.

## 2. Required content (all three options)

- Plan title and client-facing plan identity (no internal ids, no PII beyond what the plan itself displays).
- Days in order, including rest days.
- Exercise names as authored.
- Sets in order, labelled warm-up or working.
- Reps or rep range per set.
- Prescribed load with unit and mode (`bodyweight`, `added weight` kg/lb, `assisted` kg/lb).
- Rest per set, RIR per set, set/exercise/day notes.
- Trainer-selected alternatives (up to three per exercise).
- Applicable exercise and alternative video links, resolved live from the current authorized library at export time; no video URL is read from the frozen snapshot.
- For the AI prompt: the same content plus a hyperlink-formatting request.

The output must be usable for training without the platform UI; online video links still require internet.

## 3. Security and audit

- Authorization is checked before rendering; scope = current `coaching_work` in the plan workspace, plus the published-revision rule.
- Every success and every denial writes one audit event: actor, workspace, plan id, revision id/version, format (`pdf` | `excel` | `ai_prompt`), outcome. No content, notes, exercise names, URLs, client data or PII filenames.
- Denials are generic and indistinguishable from not-found.
- Export never widens access to another workspace, another client, or an unpublished revision.
- Formula-injection protection: every coach-authored Excel cell is written as a string; values beginning `=`, `+`, `-`, `@` (including after leading whitespace/control characters) are stored as text and cannot execute as a formula. Numeric cells that are generated by the system (e.g. volume) are not coach-authored and may be numeric.

## 4. `Copy Prompt for AI` content rules

The prompt MUST:

1. Contain the complete authorized plan content listed in §2 and the video URLs.
2. Ask the AI tool to format exercise names and approved alternatives as clickable hyperlinks to those URLs when possible.
3. Be professional, self-contained and copyable as-is.

The prompt MUST NOT:

1. Ask the AI to invent, replace, rename or add exercises.
2. Ask the AI to alter reps, load, rest, RIR, set counts, order or any programming value.
3. Ask the AI to generate alternatives.
4. Include content outside the selected authorized published revision.

Open: the acting role (F17-MCQ-6) and the exact prompt text/language (F17-MCQ-7). No prompt string may be authored, translated or tested before PO approval.

## 5. Layout and language (open)

The export layout, order of columns/sections, header/footer text, and AR/EN presentation are product-visible and depend on F17-MCQ-8. Constraints that hold regardless:

- Trainer-authored content is displayed as authored; no machine translation (Constitution VIII).
- Arabic renders RTL and English LTR; both must be readable and printable.
- No user-visible label, column header, button or prompt line is rendered unless it equals a PO-approved string byte-for-byte.

## 6. Test obligations (future)

Golden PDF/Excel fixtures for revision N while N+1 exists; field-coverage assertions for §2; AR/EN layout checks after MCQ-8; audit success/denial rows; injection strings (`=1+1`, `+1`, `-1`, `@SUM(A1)`, leading-space variants); prompt prohibitions (no "invent", "replace", "generate alternatives" instruction); video divergence after a library change; denial for draft, foreign workspace, Sales, client, revoked membership.
