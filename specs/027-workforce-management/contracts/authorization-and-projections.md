# Contract — Authorization and Projection Matrix

This matrix is additive to the existing D-09 permission matrix. Unlisted P7 operations are denied. Every read/write checks the signed user and current workspace membership in trusted app code and again in database authorization/RLS. PO means verified Platform Owner, not a caller-selected role string. Workspace scope is checked for every staff/client/source identifier.

## Required enforcement surfaces

1. **UI**: render only authorized fields; do not consider UI hiding to be access control.
2. **Server/API**: authorize before looking up source, replay receipt, aggregate, export or error details. Reject untrusted role/staff/workspace parameters; derive actor from verified identity.
3. **RPC**: explicit grants only; SECURITY DEFINER functions use fixed search path and narrow inputs/results. No generic “list all KPI” RPC for staff.
4. **RLS**: deny raw ledger/snapshot detail to Sales; own-compensation predicate matches authenticated staff id and workspace. Trainer check-in history predicate requires active same-workspace Trainer authorization.
5. **Exports**: Sales export returns only the same finalized own-month total fields. No export endpoint, joined report or cached artifact may bypass this contract.
6. **Replay/cache**: authorize before returning idempotent receipt or cached projection; scope cache keys to workspace, actor, role, month and finalized version.
7. **Errors**: foreign workspace, absent record, unauthorized detail and pre-finalization Sales request return a non-disclosing denial. Do not reveal client or staff existence.

## Sales response shape

Allowed fields only: `month`, `finalized` (or equivalent success state only after release), `points_total`, and the minimum period label necessary to identify that total. No per-client IDs, links, registrations, formula, category, source count, reason, deduction, adjustment, attribution, staff peers, event timestamps or live/preview total. Before month-end and PO finalization, return no total.

## Required security acceptance probes

- PO: authorized full detail; non-PO: denied full detail, manual edit, salary set, payroll approval, refund decision.
- WO/Trainer/Sales: own compensation allowed only for exact caller identity; another staff member denied.
- Trainer: all historical Weekly Check-ins in own workspace allowed; foreign workspace denied; Sales/WO denied.
- Sales: pre-close, close-not-finalized, foreign staff, foreign workspace, raw ledger, detail RPC, search, export, cached projection and replay receipt all reveal no P7 data; after close/finalization it sees only its own total.
- Revocation: revoke membership while a request waits; authorization is rechecked before commit/result.
